# AI Task Spec Template

Use this template for each implementation ticket. Keep one ticket per file and keep the scope narrow enough that a single agent can complete it without touching unrelated runtime behavior.

## Title

Short, concrete task name.

## Problem

State the exact issue or missing capability.

## Scope

State what the ticket will change.

## Non-Goals

State what the ticket must not change.

## Current Anchors

List the current files, classes, and functions this ticket depends on.

- [src/bot.py](/home/lekim/Projects/akibaCryptobot/src/bot.py)
- [src/trading/opportunity_scanner.py](/home/lekim/Projects/akibaCryptobot/src/trading/opportunity_scanner.py)

## Target Files

List the files expected to be created or modified.

## Inputs

List input data, config, events, or dependencies.

## Outputs

List outputs, side effects, emitted events, and artifacts.

## Data Contracts

Define the exact types, schemas, and invariants this ticket must obey.

## Implementation Notes

State practical constraints, edge cases, and migration rules.

## Failure Modes

List realistic failures and required handling behavior.

## Observability

List logs, metrics, counters, or traces this ticket must add or preserve.

## Tests

List required unit, integration, and regression tests.

## Rollback Plan

State how the change can be disabled or reverted safely.

## Definition of Done

List concrete acceptance checks.
